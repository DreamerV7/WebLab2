# Список задач

Веб-приложение для ведения списка задач на чистых HTML, CSS и JavaScript. Задачи сохраняются в `localStorage`.

## Возможности

- добавление, редактирование и удаление задач
- отметка о выполнении
- возможность поделиться задачей

## Запуск

Установка зависимостей и сборка не нужны.

Приложение использует ES-модули, поэтому `index.html` нужно открывать через локальный сервер, а не двойным кликом по файлу:


```bash
npx http-server
```

После этого откройте <http://localhost:8000>.

## Структура

```
index.html     разметка
css/           стили
js/            скрипты (main, state, storage, view, share)
img/icons/     иконки
fonts/         шрифты
```
